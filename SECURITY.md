# Security policy

NERVE runs in the browser and stores machine profiles locally. Please avoid posting private recordings, exported profiles, or security details in public issues.

For a suspected vulnerability, use GitHub's **Report a vulnerability** option in the repository's Security tab if available. Otherwise, open an issue containing only a non-sensitive summary and ask for a private reporting channel. Include affected versions, reproduction steps, and impact in the private report.

Security fixes will be prioritized and released through the repository. There is no guaranteed response time for this early-stage project.
